Question

Our group was tasked with analyzing the possible effect of different data collection teams on the quality and completeness of their data. Our general question is:

Are there differences between school teams as far as the consistency and completeness of data collected? How does data collected independently by schools compare to data collected by the OPIHI Coordinator in these two metrics?

Data Cleaning Approach

In order to make comparisons between schools and across years we needed to transform the various data into a common format and then stitch the data into one master csv file. We felt it was most equitable to divide the data four ways, with each person taking three to four years of data and converting it to an agreed-upon shared format for compiling. As such, each of our cleaning scripts is slightly different. All of these scripts along with an explanation of key functions can be accessed by referencing our cleaning scripts.

After converting individual years to a shared format, Kat took the separate cleaned files to stitch together. After converting individual years to a shared format, Kat took the separate cleaned files to stitch together. In order to do this, wide files were pivoted longer to match the others. Merge artifact columns were removed (e.g. “x_x, X, x_y, x_1, x_2, x_3”), column names were cleaned and columns that obviously contained the same kind of data in different places were merged. (“school” and “schoolname”, for example.) Columns that were not clear on data contents, or if the contents of the columns overlapped with different data (indicating they were two different measurements), they were not merged. Columns that contained multiple sets of information (for example, quadrat_sample contained data like “T-1 Q-4 Point 3.00”, which were separated into a transect column, a quadrat column, and a point column with each of those associated values.) Dates, organism names, and place names were standardized, and diacritical marks were removed from the main columns to avoid issues in data processing down the line. (These diacritical marks were kept in the notes alongside the original IDs.) Finally, columns were reordered to be in a more intuitive arrangement, grouping the where, when, who, what, and how’s together as much as possible. The column names were then pulled to create the data dictionary, which was manually filled out. Any uncertain columns were flagged with (uncertain) in the data dictionary.

After Kat shared this master file with us, Nick conducted small edits to further clean the data. Nick created a function which identified unique values for certain columns in the master csv containing identifying information, such as teacher/student names, and converted them to code names. The corresponding code identifiers and linked names are shared in a private csv to be sent to Dr. Philippoff.

Sampling Consistency Across Different Schools in 2019

To answer this research question, we attempted to evaluate sampling consistency per school by looking at the total number of transects done each year. If schools/teams are more consistently going to the field and running transects, they may be improving over time at coordinating these field trips and field protocols even if the students doing the transects are different per field trip. Although we thought about looking at sampling efforts as the number of field trips conducted per school each year, the amount of sampling effort expended on each field differed based on the day and the number of students there at the time. Therefore, we went with the total number of transects run as a hopefully better metric of sampling effort.

Function

This function is called New_Species_Check, and it is designed to compare the species logged in a given year’s data (for the data format up to 2020) with a master template of all the species collected across all years. It identifies unique species values by recognizing that they appear in lines 14-62 in the same column as the word “Date”, which anchors each individual form. All of the species IDs are tallied across the forms, and this list is compared against the species columns present in the master template. The output lists the total number of unique species detected, how many are new and not found on the master, and lists all the new species. As a diagnostic tool, it would be useful to quickly glance at whether new values are indeed new unlisted species, or are previously logged species that were not entered the same.

To test the function, I used the opihi_2024 data that Mei cleaned as a master template, but any file containing columns for known species would work. I tested the output by entering both the 2017 and 2018 raw data to ensure that the outputs made sense and were different.

New_Species_Check <- function(excel_file_path, sheet_name, master_template_path) {
  
  wb <- loadWorkbook(excel_file_path)
  
  # Read the master blueprint file headers exactly as written
  master_df <- read_csv(master_template_path, name_repair = "minimal", show_col_types = FALSE)
  master_species <- colnames(master_df)
  
  # Find every column coordinate where Row 1 is exactly "Date"
  entire_anchor_row <- readWorkbook(wb, sheet = sheet_name, rows = 1, colNames = FALSE, skipEmptyCols = FALSE)
  date_columns      <- which(as.character(entire_anchor_row) == "Date")
  
  if (length(date_columns) == 0) {
    stop("Could not find the word 'Date' in Row 1. Check your worksheet layout.")
  }
  
  # Read rows 14 to 62 for EVERY column on the sheet at the exact same time.
  huge_grid <- readWorkbook(
    wb, 
    sheet         = sheet_name, 
    rows          = 14:62, 
    colNames      = FALSE, 
    skipEmptyCols = FALSE, 
    skipEmptyRows = FALSE  
  )
  
  # Pull only the columns that had "Date" written in row 1
  selected_grid <- huge_grid[, date_columns, drop = FALSE]
  
  # Convert to a raw matrix first, then flatten to a character vector.
  # This completely breaks the data frame structure and guarantees separate text lines.
  all_found_organisms <- as.character(as.matrix(selected_grid))
  
  # Standardize and clean all extracted species text strings
  clean_found_organisms <- all_found_organisms %>%
    str_trim() %>%                           
    str_to_lower() %>%                       
    str_replace_all(" ", "_") %>%            
    str_replace_all("-", "_") %>%            
    str_replace_all("spp", "sp")             
  
  # Strip out worksheet layout text fillers and numeric tracking flags
  clean_found_organisms <- clean_found_organisms[
    !is.na(clean_found_organisms) & 
      clean_found_organisms != "" & 
      clean_found_organisms != "na" &
      clean_found_organisms != "organism" & 
      clean_found_organisms != "unknown" & 
      clean_found_organisms != "totals:" &
      !str_detect(clean_found_organisms, "^\\d+\\.\\d+$") & 
      !str_detect(clean_found_organisms, "^\\d+$")          
  ]
  
  # Condense down to a single unique pool of species across ALL forms at once
  clean_found_organisms <- unique(clean_found_organisms)
  
  # Evaluate what is in the Excel file versus your Master CSV blueprint
  new_species_discovered <- setdiff(clean_found_organisms, master_species)
  
  cat("\n=== SPECIES CHECK COMPLETED ===\n")
  cat(sprintf("Forms scanned: %d\n", length(date_columns)))
  cat(sprintf("Total unique species found in Excel: %d\n", length(clean_found_organisms)))
  
  if (length(new_species_discovered) > 0) {
    cat(sprintf("⚠️ ALERT: Found %d BRAND NEW species names not in your Master List:\n", length(new_species_discovered)))
    print(new_species_discovered)
  } else {
    cat("✅ SUCCESS: All species match your current Master List layout perfectly.\n")
  }
  cat("================================\n\n")
  
  return(sort(clean_found_organisms))
}
