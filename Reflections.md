### Nick Mattson
For this project, I cleaned and reformatted the 2017, 2018, and 2025 datasets. After Kat compiled our various datasets into a combined master csv, I then ran code on it to anonymize any human names in the dataset and render a new output csv as well as a key file that can be sent to Dr. Philippoff for decoding. I also cleaned the “year” column by having it pull values from the adjacent “Date” column. I created a function that can be used to parse datasets from individual years for new species entries, which are then returned as a list of unique values. My hope is that by running data from individual years and comparing the species values from those files against a master template of all species encountered over the years, it is possible to quickly identify whether “new species” are actually newly encountered species, or simply existing species with slight syntax differences. I also created the structure and formatting for the Quarto report file so that other team members could add their contributions to it.
	
Using AI to code was both very helpful but also maddeningly frustrating at times. For this particular dataset, AI helped tremendously at the start with translating the complex instructions I gave it to a code structure. I found that what worked best was to run the code that it rendered, which was much more complex than I could write independently, and compare outputs from that code against the raw data to make sure it did what I wanted it to do. AI uses extremely confident language and wanted at every step to deliver a fully mapped out solution, even when it was operating at a deficit of information, so it was helpful to imagine the first few iterations as extremely rough drafts. By evaluating each output and identifying where the code could improve, I was able to sharpen the output provided by the AI.
	
However, because of the AI’s insane confidence, I had to very carefully scrutinize outputs. For example, the AI initially read my 2017 data but rejected any species name in that file if it didn’t appear exactly in my master template file whose format I was trying to convert it to. Because there were still a huge number of columns in the output, it appeared at a glance to render correctly. Only by auditing did I discover all of the species that were not being added. I then had to explicitly ask AI to produce a list in its working memory of new species, and to sort those into the output document species list alphabetically. Ultimately, AI has no actual concept of the problem we are addressing, and the most time-consuming part of using it to code is asking it to explain its logic and evaluating whether that is actually what is wanted. I think it is highly useful for suggesting code for more complex processes, but as its suggestions grow in complexity, your understanding has to keep pace, or you won’t be able to effectively evaluate its outputs.
