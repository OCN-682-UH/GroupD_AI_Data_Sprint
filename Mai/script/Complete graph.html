Team effects: Does sampling completeness vary by Groups (Opihi and Schools)?

It was difficult to actually see the sampling completeness between students or teams with teachers? So restructuring this question to looking at the school’s sampling completeness. Schools are the proxies for the teams.

Completeness is defined as whether the team completed everthing the survey planned for. Each surveys design looks at how many transect lines to run and how many quadrats to sample on each line. A sampling completeness difference means some teams finished more of the planned sampling than others.

There are many causes, but based on this data we do not have much to work with so possible causes could be: running out of time, bad tide or weather, or skipping or not entering quadrats.

This report will identify sampling completeness by:

  1. Did students finish the protocols or surveys given to them?

  2. Did schools sample enough to detect types of spp in area?

Detection

To measure the schools sampling effort completeness we used a mathematical approacjh.

pct_quads = planned quadrats actually samples n_quads = number of quadrats planned = # of transect lines x quadrat per line (how many quadrats the protocol called for)

*_ pct_quads = 100 x n_quads / planned _*

We accounted for the sites, and chose only surveys where both the OPIHI Coordinators and a school sampled together or in another year.

show code 
# Largest number in a column, or NA (base::max so it can't be overridden)
first_num <- function(x) {
  x <- suppressWarnings(as.numeric(x))
  x <- x[!is.na(x)]
  if (length(x) > 0) base::max(x) else NA_real_
}

effort <- opihi |>
  mutate(
    yr  = year(parse_date_time(as.character(date),
                               orders = c("Ymd", "mdY", "mdy"), quiet = TRUE)),
    grp = case_when(name_of_school == "OPIHI Coordinator"   ~ "Coordinator",
                    str_detect(name_of_school, "UH|Univer") ~ "UH Manoa",
                    !is.na(name_of_school)                  ~ "K-12 schools"),
    # quadrat ID: 2016 uses quadrat_id, 2017-2020 use point_id
    quad = paste(transect_id,
                 if_else(yr == 2016, as.character(quadrat_id), as.character(point_id)))
  ) |>
  filter(yr %in% 2016:2020, grp %in% c("K-12 schools", "Coordinator")) |>
  group_by(grp, name_of_school, site_name, date) |>
  summarise(
    yr      = first(yr),
    n_quads = n_distinct(quad),                                   # sampled
    lines   = first_num(total_number_of_transect_lines),
    per_line = if (first(yr) == 2016) first_num(n_quadrats_per_transect)
               else                   first_num(quad_t),
    .groups = "drop"
  ) |>
  mutate(
    planned   = lines * per_line,                                 # planned
    pct_quads = 100 * n_quads / planned                           # % sampled
  ) |>
  filter(n_quads >= 5, is.finite(pct_quads))

The x-axis exhibits the percentage of planned quadrats sampled (pct_quads = transect lines × quadrats per line/ quadrats recorded); the y-axis lists schools, ordered from lowest to highest completeness. Blue circles show each school’s median across its surveys (number of surveys in parentheses); orange diamonds show the Coordinator’s median effort at the same sites that school sampled.
